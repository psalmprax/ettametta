## API Endpoint Summary

| Module | Endpoints | Description |
|--------|-----------|-------------|
| `auth` | POST /register, /login, /me | User authentication |
| `discovery` | GET /trends, /search, /niches | Content discovery |
| `video` | POST /transform, /generate, /jobs | Video generation |
| `publish` | POST /post, /schedule, /accounts | Publishing |
| `analytics` | GET /posts, /report, /stats | Analytics |
| `monetization` | POST /links, /empire/* | Monetization |
| `billing` | POST /create-checkout-session | Subscriptions |
| `nexus` | POST /compose | Video composition |
| `settings` | GET/PUT /preferences | User settings |
| `admin` | /* | Admin operations |
