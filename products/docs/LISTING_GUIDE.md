## GUMROAD (gumroad.com)

### For Each Product:
1. Go to https://gumroad.com/products/new
2. Enter product name from table above
3. Set price from table above
4. Upload thumbnail as cover image
5. Upload product file(s)
6. Paste description from gumroad_description_clean.txt
7. Add tags from metadata.json
8. Click Save draft → Preview → Publish
