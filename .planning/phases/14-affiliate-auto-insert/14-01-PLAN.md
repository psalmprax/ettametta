# Phase 14-01: Affiliate Auto-Insert

## Goal

Wire up the Transformation page's "Auto-Inject Affiliate Nodes" button so it actually burns affiliate URLs into the rendered video via FFmpeg drawtext, with per-link impression tracking.

**What ships in this phase:**

* `POST /api/v1/video/auto-insert-links` accepts `{job_id}`, looks up the completed job, calls `MonetizationEngine.process_video_with_links()` which invokes `FFmpegTransformer.draw_text_overlay()` with the affiliate URL visible in the rendered text
* `_plan_link_insertion` always includes the actual `link` URL (not just the LLM's narrative text) in the `script_addition` field, sanitized for FFmpeg's `drawtext` filter
* `_plan_link_insertion` reads `AffiliateLinkDB.link` (not the non-existent `url` field) so the LLM prompt contains real URLs
* After a successful render, each linked `AffiliateLinkDB.impression_count` is incremented (the column was added in an earlier migration)
* The Transformation page frontend already calls the correct endpoint with `{job_id}` — no frontend changes needed
* 14 unit tests in `src/api/tests/test_affiliate_auto_insert.py` covering: endpoint validation, job lookup, output path resolution, full integration with mocked monetization engine, impression counter checks, and error handling

## Tasks

- [x] T1. **Backend endpoint** — `POST /api/v1/video/auto-insert-links` with `AutoLinkRequest(job_id, video_path, niche, script_content)`. - [x] T2. **Script addition with URL** — `_plan_link_insertion` now appends `"<CTA>: <URL>"` to each overlay/end_screen insertion's `script_addition` so FFmpeg drawtext renders a visible URL.

- [x] T4. **Impression tracking** — `process_video_with_links` increments `AffiliateLinkDB.impression_count` for every link successfully burned into the rendered video.

## Rollback

No DB migration involved. To disable auto-insert, remove or comment out the `POST /video/auto-insert-links` route. The `impression_count` increments are best-effort and non-transactional — rolling back renders does not decrement counters (acceptable for an impressions metric).
