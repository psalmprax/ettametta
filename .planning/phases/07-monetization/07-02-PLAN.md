# Phase 7: Monetization — PLAN 02

## Goal
Verify and document affiliate link insertion, revenue tracking, and credit management.

## Context
Phase 7 covers MONET-01 (affiliate links), MONET-02 (revenue tracking), MONET-03 (credits). Full implementation exists:

### Existing Code
- **monetization/service.py**: `MonetizationEngine` — product recommendation, AI-driven affiliate link insertion planning, video overlay via FFmpeg, EPM calculation
- **monetization/orchestrator.py**: `MonetizationOrchestrator` — 8 strategies (commerce, affiliate, lead_gen, digital_product, membership, course, sponsorship, crypto), circuit-breaker failover
- **monetization/revenue_service.py**: `MonetizationService.get_revenue_summary()` — RPM-based revenue estimation, platform breakdown, daily trends, goals tracking
- **monetization/strategies/**: affiliate.py, commerce.py, lead_gen.py, digital_product.py, membership.py, course.py, sponsorship.py, crypto.py
- **affiliate/service.py**: `AffiliateService` — Amazon PA-API 5.0 with SigV4, Impact Radius, ShareASale. Circuit breakers, retries. Disabled by default (`ENABLE_AFFILIATE_API`)
- **payment/stripe_service.py**: `PaymentService` — Stripe customer/subscription, 5 tiers (free→studio), webhook handling
- **payment/credit_service.py**: `CreditService` — full credit system with `consume_credits()`, row-level locking, 17 action costs with tier discounts, referral codes (50 credits reward)
- **payment/paypal_service.py**: `PayPalService` — sandbox/live checkout, subscription, webhook

### API Routes
- `/recommend-links`, `/auto-merch`, `/report`, `/links` (CRUD), `/promo/generate`
- `/empire/*` (metrics, activity, blueprints, network, clone)
- `/revenue/summary`, `/goals`, `/platforms`
- `/create-checkout-session`, `/subscription`, `/cancel`, `/webhook` (Stripe)
- `/balance`, `/transactions`, `/packages`, `/purchase`, `/costs`, `/referral/*`

### Frontend
- `apps/dashboard/src/app/credits/page.tsx` — Full credits dashboard: vault, acquisition (Stripe checkout), transaction ledger, referral network

### Implementation Status
- **Affiliate link insertion**: Implemented (AI planning + FFmpeg overlay)
- **Revenue tracking**: Implemented (RPM-based from view/click counts)
- **Credit management**: Fully implemented (balance, consumption, purchase, referrals)
