## Objective

Wire up the "Auto-Merch" button on the Empire page and the `commerce_service.py` to real Shopify Admin API + Printful Print-on-Demand integration, so trending content can be automatically turned into merchandise.

---

## Implementation

### 1. CommerceService (`src/services/monetization/commerce_service.py`)

- **`get_relevant_products(niche)`** — Fetches products from Shopify Admin API by niche title match. Falls back to `AffiliateLinkDB` entries if Shopify is unavailable.
- **`_fetch_from_shopify()`** — Calls `GET /admin/api/2024-01/products.json` with `X-Shopify-Access-Token`. Returns normalized product list with URLs, prices, and source tags.
- **`_get_shopify_creds()`** — Reads `SHOPIFY_SHOP_URL` and `SHOPIFY_ACCESS_TOKEN` from `SystemSettings` DB table.
- **`generate_checkout_link()`** — Returns Shopify cart link format.
- **Fallback chain**: Shopify API → AffiliateLinkDB → Empty list (graceful degradation)

### 2. AutoMerchService (`src/services/monetization/auto_merch.py`)

- **`generate_and_publish_merch(niche)`** — End-to-end "Reverse Monetization" pipeline:
  1. AI generates a visual design prompt from the niche/trend
  2. pollinations.ai creates a 1024×1024 PNG
  3. Printful API publishes the design as a Men's Premium Tee ($24.99)
- **Hardened**: Raises `ValueError` if `PRINTFUL_API_KEY` is missing — no silent mock products

### 5. Frontend (`apps/dashboard/src/app/empire/page.tsx`)

The Empire page includes a **Commerce Matrix** tab with:
- **Store Sync panel** — Shows platform, status, product count. Manual Refresh button calls `POST /monetization/commerce/sync`
- **Reverse Monetization panel** — "Scan Viral Design Opportunity" generates merch from trending niches
- **Live status indicator** — Green dot when Shopify is connected

### 6. Integration Points

- **OpenClaw Telegram bot** — `trigger_auto_merch()` skill calls `/monetization/auto-merch` remotely
- **Optimization Service** — Auto-triggers merch generation for high-scoring content
- **Settings UI** — `/settings` exposes shopify keys, `/settings/verify/shopify` tests connectivity
