# Phase 19: Video Enhancements — PLAN 01

## Goal
Implement remaining video processing features: background removal, sound design, and dynamic watermarking.

## Tasks

### T1: Background Removal (`src/services/video_engine/background_remover.py`)
- `remove_background(video_path, method='auto') -> output_path`
- Support: FFmpeg chromakey, rembg (ML-based), solid color replacement
- Add `BACKGROUND_REMOVAL_ENABLED` to settings

### T2: Sound Design + Music Addition (`src/services/video_engine/sound_designer.py`)
- `add_background_music(video_path, music_path, volume=0.3) -> output_path`
- `generate_ambient_sound(duration, style) -> audio_path`
- `mix_audio_tracks(tracks: list[AudioTrack]) -> output_path`
- FFmpeg-based audio mixing with fade in/out

### T3: Dynamic Watermarking (`src/services/video_engine/watermarker.py`)
- `add_watermark(video_path, watermark, position='bottom-right', opacity=0.5) -> output_path`
- Support: text watermark, image watermark, animated watermark
- `burn_branding(video_path, brand_config) -> output_path`

### T4: API Endpoints
- Add `/api/v1/video/enhance/background` route
- Add `/api/v1/video/enhance/sound` route
- Add `/api/v1/video/enhance/watermark` route

### T5: Frontend Integration
- Add enhancement options to creation page
- Add watermark preview component

## Success Criteria
1. User can remove video background and replace with solid color/image
2. User can add background music with volume control
3. User can add text/image watermark to videos
4. All enhancements integrate with existing job pipeline
